# СТО Касса

Учёт заказов для СТО: запчасти, наценка, работа, мастера, общие расходы, поиск и аналитика.

- `index.html` — приложение целиком. Работает без интернета, данные хранятся на устройстве.
- `sw.js`, `manifest.json`, `icon.png` — нужны, чтобы приложение ставилось на экран телефона и открывалось без сети.
- `claude-version/sto-kassa.html` — исходник. Из него `build.py` собирает `index.html`; он же публикуется в Claude (там есть распознавание чека по фото).
- `build.py` — сборка: `python3 build.py`.
- `api.php` — серверная часть для хранения данных на своём хостинге.

## Установка на iPhone

1. Откройте ссылку сайта в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Запустите с иконки один раз при интернете. Дальше приложение работает без сети.

Данные вводите уже с иконки и регулярно сохраняйте копию кнопкой «Копия».

## Синхронизация

Рядом с приложением на хостинге лежит `api.php`. Он хранит заказы и расходы в папке `data/` (закрыта от просмотра) и отдаёт их приложению по паролю. Первый пароль, с которым подключится приложение, становится паролем кассы. В приложении: «Копия» → «Синхронизация с сервером».

Для размещения нужен хостинг с PHP и https. На сайт загружаются: `index.html`, `sw.js`, `manifest.json`, `icon.png`, `api.php`.
